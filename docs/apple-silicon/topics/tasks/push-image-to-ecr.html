Push the Docker image to Amazon ECR

Upload the image to a private Amazon ECR repository so that AWS can run it.

  • The Docker image is built.
  • The AWS CLI is installed and configured.
  • A private ECR repository named helloworld exists.
CAUTION:
Do not publish your AWS account ID, access keys or tokens in public repositories or documents.
  1. Authenticate Docker with Amazon ECR: 
    aws ecr get-login-password --region <region> | docker login --username AWS --password-stdin <account-id>.dkr.ecr.<region>.amazonaws.com
    The terminal displays Login Succeeded.
  2. Tag the image with the repository address: 
    docker tag helloworld:latest <account-id>.dkr.ecr.<region>.amazonaws.com/helloworld:latest
  3. Push the image to the repository: 
    docker push <account-id>.dkr.ecr.<region>.amazonaws.com/helloworld:latest
The image appears in the helloworld repository in the Amazon ECR console.
