Build the Docker image

Package the Spring Boot application into a Docker image that can run on AWS.

  • JDK 17, Maven and Docker Desktop are installed.
  • The application runs locally.
  • A Dockerfile exists in the project root folder.
Warning:
AWS resources can incur costs. Delete resources you no longer need after testing.
  1. Open a terminal in the project root folder.
  2. Package the application into a JAR file: 
    mvn clean package
    The file helloworld-0.0.1-SNAPSHOT.jar is created in the target folder.
  3. Build the image for the Linux/AMD64 architecture: 
    docker build --platform linux/amd64 -t helloworld .
The image helloworld is created.
