Troubleshooting

Common problems when containerizing and deploying the application, with causes and solutions.

Problem Cause Solution
The image builds on your computer but the container does not run on AWS Fargate. The image was built for ARM64 (Apple Silicon), but Fargate runs Linux/AMD64. Rebuild the image with docker build --platform linux/amd64 -t helloworld .
The application is not reachable from outside the container. The application listens only on the local address. In application.properties, set server.address=0.0.0.0 and server.port=8080.
The docker build command fails because files are not found. The Dockerfile is not in the project root folder, so Docker uses the wrong build context. Move the Dockerfile to the same folder as pom.xml and run the command from that folder.
You cannot open the ECS service directly in a browser. The service runs in a private subnet. Open the DNS name of the Application Load Balancer instead.
