What is Docker?

Docker packages an application and everything it needs into a portable unit called a container.

A container is a lightweight, isolated environment that runs an application together with its dependencies. A container behaves the same way on a laptop, on a test server and in the cloud.

Docker works with four main components:

Docker client
The command-line tool you use to send commands, such as docker build.
Docker daemon
The background service that builds, runs and manages containers.
Image
A read-only package that contains the files, libraries and configuration needed to run a container.
Registry
A storage location for images. Docker Hub is a public registry. Amazon ECR is a private registry on AWS.

When you run an image, it becomes a container.
